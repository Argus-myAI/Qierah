Qierah Very Simple Video Editor

Coming soon · Preparing for Microsoft Store

The Windows desktop editor is in development. It is designed for simple editing with 1,000 overlays, photos, text, voice recording, and landscape, portrait and square export. It has not been approved by Microsoft Store and no public download is available here.

For authorised testers: include your application version, Windows version, what you expected to happen, what happened instead and the steps that reproduce the problem. Share only a non-sensitive example if one is needed.

Microphone and local files

Voice recording needs an available microphone and permission for desktop apps in Windows microphone privacy settings. Recordings and project media stay on your device unless you choose to share them or use a separate sync service. Keep your original media available when reopening a project.

Software creation and future tools

For a custom program or productivity tool, tell us the task you want to simplify, the device or platform you use and what a useful outcome would look like. Scope, availability, data handling and support are agreed for each project.

Ask a question or report a problem

Email info@qierah.com for product support, general questions or software development enquiries. You can also use the Qierah public enquiry tracker on GitHub for non-sensitive questions and development feedback. A GitHub account is needed to post there.

GitHub Issues are public. Do not include personal documents, passwords, API keys, private recordings or confidential project files. For a sensitive matter, contact info@qierah.com with a brief description first. Do not send passwords or access tokens by email.
